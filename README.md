# The 90% Status Report

A one-line status report for make.fun's "Status Report Comedy Sprint". It takes the most universal lie in software — the feature that is always 90% done — and reports it with a straight face, week after week, with only the confidence improving. It is the kind of update every team has received, written exactly the way a real status report would be written, which is why it stings and why it is funny.

> Status report: the feature is 90% done, the same 90% it was last week, but this week we are 90% done with much more confidence.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

This writes the line to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `/output`). Standard library only, no network, no randomness — the same line on every run, because a status report that changed its story would be the one honest thing in the sprint.

## Why it works

The joke has three beats in one sentence: the familiar number (90% done), the reveal that the number has not moved since last week, and the twist that the only thing that improved is the confidence. Each beat is something a real status report could say, which is what makes the whole thing land — it is a parody that could pass as the original.
